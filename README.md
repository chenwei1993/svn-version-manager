# SVN版本管理

**SVN版本管理**是一个基于 **Wails v2 + Go + Vue 3** 的桌面工具，用来记录每次功能开发产生的变更，并一键导出对应的代码文件。

## 它能做什么

- **项目管理**：登记本机的 SVN 工作副本，自动读取仓库地址与分支路径。
- **功能记录**：每次开发新建一条功能记录，填写版本、说明、状态。
- **数据库变更登记**：结构化记录「新增表 / 新增字段 / 修改字段 / 删除字段 / 索引」等变更。
- **SVN 提交关联**：读取 `svn log`，查看提交改动了哪些文件，勾选后关联到功能。
- **自动同步**：在功能详情开启后，打开功能会自动把「我的 SVN 账号」在已关联版本之后的新提交加入该功能；也可以手动点击「同步新提交」。
- **一键导出**：按关联提交的版本（revision）从仓库导出文件快照，自动生成 `变更清单.md`；如登记了数据库变更，还会生成 `数据库变更.sql`，并打包成 zip。
  导出的是**提交时的代码版本**，不受当前工作副本后续改动影响。

## 环境要求

| 依赖 | 说明 |
| --- | --- |
| Go 1.24+ | 构建后端 |
| Node.js 18+ | 构建前端 |
| Wails CLI v2 | `go install github.com/wailsapp/wails/v2/cmd/wails@latest` |
| svn 命令行 | **必须**。TortoiseSVN 安装时需勾选 `command line client tools` |

### 补装 svn 命令行

如果安装 TortoiseSVN 时没有勾选命令行工具：

1. 重新运行 TortoiseSVN 安装包，选择 **Modify**；
2. 勾选 **command line client tools**；
3. 完成安装后，在本软件的「设置 → SVN」里点击「自动检测」，或手动选择
   `C:\Program Files\TortoiseSVN\bin\svn.exe`。

私有仓库的账号密码由系统 SVN 凭据缓存管理，本软件不保存密码。请先用 TortoiseSVN 正常访问一次仓库。

## 开发与构建

```bash
# 开发模式（热更新）
wails dev

# 生产构建，输出到 build/bin/SVN版本管理.exe
wails build
```

也可以在浏览器中调试前端：运行 `wails dev` 后打开 <http://localhost:34115>。

## 使用流程

1. 打开「项目管理」→「添加项目」，选择 SVN 工作副本目录。
2. 打开「功能记录」→「新建功能」，填写功能名称、版本和说明。
3. 在功能详情里登记数据库变更（新增表、新增字段等）。
4. 打开「SVN 提交」，勾选本次功能相关的提交，选择目标功能后点击「关联到功能」。
5. 回到功能详情，进入「导出」标签页，勾选要导出的文件，选择目录后点击「导出选中文件」。
6. 导出目录下会生成：
   - `功能名_时间/`：按项目相对路径还原的代码文件
   - `功能名_时间.zip`：打包后的交付文件
   - `变更清单.md`：功能说明、数据库变更、提交记录、文件清单
   - `数据库变更.sql`：根据数据库变更记录生成的 SQL 草稿（如有数据库变更）

## 设置

右上角「设置」中可配置：

- **通用**：默认导出目录、默认读取提交数
- **SVN**：`svn.exe` 路径、我的 SVN 账号
- **数据与配置**：查看配置目录、数据目录，或把数据库复制到新目录

## 数据存储

默认配置和数据目录：

```
%APPDATA%\project-manage\
├── config.json          # 数据目录等启动配置
└── project-manage.db    # SQLite 数据库
```

数据目录可以在「设置 → 数据与配置」中查看或更改。删除 `project-manage.db` 即可清空所有记录（不会影响磁盘上的项目代码）。

## 目录结构

```
app.go                       Wails 绑定层（前端可调用的方法）
main.go                      应用入口
internal/model/              数据模型
internal/store/              SQLite 存储
internal/svnx/               svn 命令行封装
internal/exporter/           文件导出与 zip 打包
frontend/src/                Vue 3 界面
```

## 已知限制

- SVN 相关功能依赖本机 `svn` 命令行。
- 读取提交时使用 `--non-interactive`，若凭据未缓存会给出错误提示。
- 导出时同一文件取关联提交中的最高版本；已删除的文件会跳过并记录在导出结果中。
